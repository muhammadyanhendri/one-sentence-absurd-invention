A make.fun entry for "One-Sentence Absurd Invention Pitch": the program writes exactly one sentence to `entry.txt` in the output directory — a pitch for a ridiculous invention that fixes a tiny everyday annoyance. The pitch is **The Apology Remote**: a TV remote that hides itself in the sofa cushions every time you shout for it, and only wriggles back out once you apologise to it out loud — 161 characters, one sentence, no trailing newline.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
